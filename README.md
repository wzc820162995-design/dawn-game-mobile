# 黎明游戏 手机版

在线地址：
<https://wzc820162995-design.github.io/dawn-game-mobile/>

使用 GitHub Pages 静态托管，不依赖本机保持开机。

微信可直接打开的 HTML5 Canvas 版本。玩法沿用桌面版，移动改为左下角触屏摇杆。

## 本地运行

```powershell
cd F:\501\黎明游戏_手机版
python -m http.server 8090 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8090/`。

## 操作

- 在画面左下区域按住并拖动，生成触屏摇杆。
- 拖动方向为角色移动方向，松手立即停止。
- 默认同时显示英文和中文。
- 升级时点击一张卡。
- 点击右上角暂停按钮暂停，点击画面继续。
- 结算后点击任意位置重开。

## 文件

- `index.html`: 页面和移动端视口设置。
- `style.css`: 全屏手机布局。
- `game-core.js`: 纯游戏规则和数值流程。
- `game.js`: 画布渲染、触屏摇杆、音效和界面。
- `data/game.json`: 平衡数值。
- `assets/`: 像素素材和手机图标。
- `sounds/`: 合成音效。
